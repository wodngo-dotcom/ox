# OX 퀴즈 (미취학 아동용)

빌드 과정 없이 바로 실행되는 반응형 웹앱입니다.

## 실행 방법

`index.html`을 브라우저로 직접 열거나, 로컬 서버로 실행하세요.

```bash
npx serve .
# 또는
python3 -m http.server 8000
```

## 구성

- `index.html` — 화면 구조 (시작 / 게임 / 이름 입력 / 게임오버)
- `style.css` — 반응형 스타일
- `script.js` — 게임 로직 (타이머, TTS, 효과음, TOP3 랭킹 저장)
- `questions.js` — 200개 OX 문제 + 해설 데이터

## 주요 기능

- 문제 자동 TTS 낭독, 정답 해설 자동 TTS 낭독
- 20초 제한시간을 원형 게이지로 표시 + 똑딱 효과음 (시간 초과 시 자동 오답 처리)
- 한 문제라도 틀리거나 시간 초과되면 바로 게임오버
- TOP3 랭킹 저장(localStorage): 점수가 TOP3에 들면 이름 입력 화면을 거쳐 순위표에 반영, 못 들면 이번 점수와 현재 순위표만 표시
